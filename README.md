# MINI POS
## Point of Sale Management System

Aplikasi kasir berbasis Linux dengan dua antarmuka:
CLI dan Web GUI.

### Teknologi
- Bash Shell Script
- HTML
- CSS
- JavaScript
- Apache
- Apache CGI
- MySQL

### Fitur
1. Manajemen Barang
2. Pengelolaan Stok
3. Transaksi Penjualan
4. Riwayat Transaksi
5. Laporan Penjualan

### Arsitektur
- Bash sebagai backend utama.
- CLI sebagai antarmuka terminal.
- Web GUI sebagai antarmuka browser.
- Apache CGI sebagai penghubung.
- MySQL sebagai database.

### Autentikasi
Satu akun Admin untuk seluruh aplikasi.
